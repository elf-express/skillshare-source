# skillshare-source

Elf Express team source for personal AI CLI skills, synced via [skillshare](https://skillshare.runkids.cc).

This repository stores the single source of truth for individual AI CLI skills
(per-member personal skills). For **team-wide standards**, see
[elf-express/org-skills](https://github.com/elf-express/org-skills).

## Sync setup

```powershell
skillshare init -g --remote https://github.com/elf-express/skillshare-source.git
```

See `elf-express/org-skills` README for full team-lead setup guide.
