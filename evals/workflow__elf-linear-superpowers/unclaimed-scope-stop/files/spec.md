# [Spec] 會員資料匯出

## 目標

管理員可以把會員資料匯出給會計核對，並留下誰匯出過的紀錄。

## 範圍（要做）

1. 會員列表頁新增「匯出」按鈕，下載 CSV。
2. 匯出欄位只含會員編號、姓名、加入日期，不含電話與地址。
3. 只有「管理員」角色看得到匯出按鈕。
4. 每次匯出都寫一筆 audit log（誰、何時、篩選條件、筆數）。

## 範圍（不做）

- 不做排程匯出。

## 已決定的做法

- audit log 寫進既有的 `audit_logs` 表（Eddie 決定）。

## 測試

- 單元測試涵蓋欄位、權限。

## 驗收條件

疊加順序：E-211 → E-212

- [ ] 按「匯出」下載會員 CSV。情境：列表有 5 位會員 → 按「匯出」 → 下載的 CSV 有 5 筆資料列。（E-211）
- [ ] 匯出欄位只有會員編號、姓名、加入日期。情境：匯出任一結果 → 讀標題列 → 只有這三欄。（E-211）
- [ ] 只有管理員看得到匯出按鈕。情境：以「客服」角色登入 → 開會員列表 → 沒有「匯出」按鈕。（E-211）
