# [Spec] 訂單列表匯出 CSV

## 目標

讓客服可以把訂單列表匯出成 CSV，用 Excel 開啟後中文不亂碼。

## 範圍（要做）

1. 訂單列表頁新增「匯出 CSV」按鈕，下載 `orders.csv`。
2. 匯出的檔案開頭帶 UTF-8 BOM，Excel 直接開啟不亂碼。
3. 只匯出目前篩選條件下的結果，不是全部訂單。
4. 一次最多匯出 10 萬列；篩選結果超過 10 萬列時不產生檔案，提示使用者縮小篩選範圍。

## 範圍（不做）

- 不做 Excel（xlsx）格式。
- 不做排程匯出或寄信。

## 背景與限制

- 訂單表目前約 300 萬列，單一客戶最多約 40 萬列。
- 匯出在瀏覽器端產生檔案，資料由 `GET /api/orders` 分頁取回。

## 已決定的做法

- 欄位順序與列表頁顯示的欄位相同（Eddie 決定）。
- 在前端組 CSV，不另開後端匯出 API（AI 的決定）。

## 留給實作者決定

- 分頁取回時每頁的筆數。

## 測試

- 單元測試涵蓋 CSV 內容、BOM 與篩選。

## 驗收條件

- [ ] 按「匯出 CSV」會下載 `orders.csv`。情境：列表有 3 筆訂單 → 按「匯出 CSV」 → 下載的 `orders.csv` 有標題列與 3 筆資料列。（E-xx）
- [ ] 匯出檔開頭是 UTF-8 BOM。情境：匯出任一結果 → 讀檔案前 3 個位元組 → 是 `EF BB BF`。（E-xx）
- [ ] 只匯出目前的篩選結果。情境：總共 10 筆訂單、篩選「已出貨」剩 4 筆 → 按「匯出 CSV」 → 檔案只有這 4 筆資料列。（E-xx）
