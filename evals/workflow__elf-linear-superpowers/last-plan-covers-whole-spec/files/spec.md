# [Spec] 每月營收報表

## 目標

財務每月初可以下載上個月的營收報表，跨時區的分店也對得上。

## 範圍（要做）

1. 報表依分店列出上個月營收合計。
2. 報表每一列要含分店的時區欄位（例 `Asia/Taipei`）。
3. 報表可以下載成 CSV。
4. 每月 1 日 06:00 自動產生上個月的報表。

## 範圍（不做）

- 不做圖表。

## 已決定的做法

- 營收以分店當地時區切月份（Eddie 決定）。

## 測試

- 單元測試涵蓋合計、時區欄位、CSV 與排程。

## 驗收條件

疊加順序：E-301 → E-302

- [ ] 依分店列出上個月營收合計。情境：A 店上月有 3 筆共 900 元 → 產生報表 → A 店那一列合計 900。（E-301）
- [ ] 每一列含分店時區欄位。情境：B 店時區是 `Asia/Tokyo` → 產生報表 → B 店那一列的時區欄是 `Asia/Tokyo`。（E-301）
- [ ] 報表可以下載成 CSV。情境：報表已產生 → 按「下載 CSV」 → 取得 `revenue-2026-10.csv`。（E-302）
- [ ] 每月 1 日 06:00 自動產生上月報表。情境：時間到 11/1 06:00 → 排程執行 → 產生 2026-10 的報表。（E-302）

## 待決問題

無。
