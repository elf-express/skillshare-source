# [Spec] 每日匯率快取

## 目標

報價單換算外幣時不必每次都呼叫外部匯率 API，降低費用與延遲。

## 範圍（要做）

1. 同一天、同一幣別的匯率只向外部 API 查一次，之後從快取取。
2. 服務重啟後當天的匯率仍在，不重新呼叫外部 API。

## 範圍（不做）

- 不做歷史匯率查詢。

## 背景與限制

- 外部 API 按次計費，每月上限 5,000 次。
- 服務每天會因部署重啟 2–3 次。

## 已決定的做法

- 匯率快取放 PostgreSQL 的 `fx_rates` 表，重啟不能遺失（Eddie 決定）。
- 主鍵是 `(rate_date, currency)`（AI 的決定）。

## 留給實作者決定

- 快取查詢的函式命名。

## 測試

- 單元測試涵蓋「同日同幣別第二次不呼叫外部 API」。
